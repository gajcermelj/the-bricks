The Bricks — Tenis Royale
Brskalniška igra v slogu breakout/tennis, zgrajena s HTML, CSS in JavaScript (jQuery). Igraj na spletu ali lokalno brez namestitve.
🔗 Live demo: gajcermelj.github.io/the-bricks

📸 Pregled
Tenis Royale je arkadna igra, v kateri usmerjate žogico in tekmujete proti računalniku ali resničnemu nasprotniku. Igra podpira dva načina igranja — za enega ali dva igralca — ter prikazuje rezultat in čas v realnem času.

🛠️ Tehnologije

HTML5 Canvas — risanje igre
CSS3 — oblikovanje vmesnika
JavaScript (jQuery 4.0) — logika igre
SweetAlert2 — pojavna okna (credits, obvestila)
